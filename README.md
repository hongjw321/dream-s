# 몽환 Dream-S — AI 꿈해몽 서비스 시제품

## 브랜드
- 이름: 몽환 (Dream-S)
- 슬로건: 꿈을 읽다, 무의식을 만나다.
- 콘셉트: 칼 융의 무의식·상징 심리학 관점과 동양 전통 꿈해몽을 함께 살펴보는 AI 꿈 분석 서비스

## 현재 구현
- 반응형 몽환적 랜딩 페이지 및 움직이는 달·구름·별빛·꿈의 문 그래픽
- 꿈 내용, 꿈속 감정, 꿈을 꾼 시기를 입력하는 폼
- 꿈 상징 카테고리 소개
- 5단계 꿈 분석 리포트 소개

## 분석 리포트 구성
1. 꿈의 요약과 분위기
2. 칼 융의 무의식 관점 심리학적 분석
3. 전통적 길흉화복 해석
4. 영화 예고편 스타일의 심리 시나리오
5. AI 이미지 생성을 위한 영문 프롬프트

## GitHub Pages 배포
1. 저장소 Settings → Pages로 이동합니다.
2. Source를 Deploy from a branch로 설정합니다.
3. Branch는 main, Folder는 /(root)를 선택하고 Save를 누릅니다.
4. 배포 완료 후 https://hongjw321.github.io/saju-taro/ 에서 확인합니다.

## 주의: 시제품 단계
현재는 프론트엔드 화면과 입력 폼만 구현되어 있습니다. 실제 AI 꿈 분석, AI 이미지 생성, 회원가입, 꿈 기록 저장, 결제 및 PDF 생성은 아직 연결되지 않았습니다. 입력한 꿈 내용은 현재 브라우저 sessionStorage에 임시 초안으로 저장됩니다.

상용화 전에는 서버 측 AI API 연동, 호출량·비용 제한, 개인정보 처리방침, 이용약관, 환불정책 및 보안 설계가 필요합니다. 꿈 해석은 심리학적·문화적 관점의 참고 콘텐츠이며 미래를 확정적으로 예측하지 않는다고 안내해야 합니다.
