# BRAND NAME — 사주·타로 홈페이지 시제품

## 현재 구현
- 모던 프리미엄 반응형 랜딩 페이지
- 이름, 생년월일, 양력/음력, 태어난 시간, 성별 입력 폼
- 사주·타로 서비스 소개 및 PDF 리포트 소개

## GitHub Pages 배포
1. 저장소 Settings → Pages로 이동합니다.
2. Build and deployment의 Source를 Deploy from a branch로 설정합니다.
3. Branch는 main, Folder는 /(root)를 선택하고 Save를 누릅니다.
4. 배포가 완료되면 https://hongjw321.github.io/saju-taro/ 에서 확인합니다.

## 주의: 시제품 단계
현재는 프론트엔드 디자인과 입력 화면만 구현되어 있습니다. 실제 만세력 계산, 절기·음력 윤달 보정, 사주 해석, 타로 추첨/리딩, 결제, 주문 관리, PDF 리포트 생성은 아직 연결되지 않았습니다. 고객에게 실제 분석 결과처럼 판매하면 안 됩니다.

상용화 전에는 검증된 역법 계산 모듈, AI 해석 검증, 서버 측 결제 검증, 개인정보 처리방침·이용약관·환불정책 및 보안 설계가 필요합니다.
